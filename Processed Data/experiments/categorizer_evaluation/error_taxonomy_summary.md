## 5. Implications for retrieval-augmented extraction

- **CATEGORY_PRIORITY** errors are fixed by changing the categoriser (V2: first recognised colour after compound-colour normalisation; not “always prefer REDTYPE”), not by RAG.
- **CONTAMINATION / JUNK** need better parsing or retrieval of a clean treatment boundary — RAG can help if retrieval returns the right block.
- **FRUIT_BERRY / FALSE_POSITIVE** are prompt/RAG targets: retrieve exemplars that distinguish floral vs fruit colour.
- **MULTI_COLOUR** benefits from few-shot exemplars with an explicit primary-colour rule.
